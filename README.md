Revisar instalacion de node, npm y angular con:
Node: "node -v"
npm: "npm -v"
Angular: "ng version"

Si no están instalados:
Node: Descargar de la página oficial https://nodejs.org/es
Modulos de npm: "npm install"
Angular: "npm install -g @angular/cli"
Dependencias de azure: "npm install @azure/msal-browser @azure/msal-angular"
